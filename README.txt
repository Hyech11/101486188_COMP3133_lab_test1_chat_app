[Description]
This project is a real-time chat application created for Lab Test 1.
It allows users to sign up, log in, join rooms (e.g., DevOps, Sports), and chat with others in real-time.
All user data and chat messages are saved in MongoDB.

[Key Features]
1. Sign Up & Login: Users can create an account and log in.
2. Rooms: Users can join or leave specific chat rooms.
3. Real-time Chat: Messages are sent instantly using Socket.io.
4. Typing Indicator: Shows when someone is typing.
5. Database: Uses MongoDB to store user info and chat history.

[Tech Stack]
- Node.js
- Express
- Socket.io
- MongoDB (Mongoose)
- HTML/CSS/jQuery

[How to Run]
1. Open the project folder in terminal.
2. Run 'npm install' to install dependencies.
3. Check 'server.js' for MongoDB connection string.
4. Run 'node server.js'.
5. Open browser and go to http://localhost:3000.
